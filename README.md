# ARI Deals

Assistente de propostas comerciais criado com apoio do ChatGPT. Organiza as informações do cliente, define o escopo e prepara documentos para revisão.

## Serviços disponíveis

- Criação de sites.
- Automação de processos.
- Análise de dados e relatórios.
- Suporte e manutenção.

## Como funciona

1. Recebe um briefing ou coleta as informações por perguntas.
2. Identifica o objetivo, as entregas e os dados faltantes.
3. Organiza prazos, valores e condições comerciais.
4. Apresenta um resumo para aprovação.
5. Gera a proposta em Word, que pode ser exportada para PDF.

## Instruções

O arquivo SKILL.md reúne as instruções do assistente. Para usar o projeto, é necessário um ambiente de IA capaz de ler essas instruções e gerar documentos.

## Simulação

O projeto foi testado com uma proposta fictícia de automação de atendimento para a empresa Torres Ruaro.

O exemplo inclui escopo, responsabilidades, critérios de aceite, implantação e suporte mensal. Os dados e valores são demonstrativos.

## Estado atual

A geração de uma proposta de automação foi testada. Os fluxos de sites, análise de dados e suporte ainda precisam de testes específicos.

## Origem

Projeto de estudo adaptado de uma atividade de curso, com revisão das instruções para os quatro serviços descritos acima.
